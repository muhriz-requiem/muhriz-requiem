# “Indeed, Allah will not change the condition of a people until they change what is in themselves.” — Qur’an 13:11

I'm interested in systems, the way things connect. As for this GitHub page specifically: I love exploring my interests via these projects, learning more everyday.

What's here thus far:

- **[ai-agent-coding-system-v3](https://github.com/muhriz-requiem/ai-agent-coding-system-v3)** — a multi-agent system that builds software under tests it cannot rewrite, with every escalation diagnosed and the costs documented next to the wins. Rebuilt after the post-mortem below; every fix traces to a specific failure.
- **[ai-agent-coding-system](https://github.com/muhriz-requiem/ai-agent-coding-system)** — the predecessor, published as a failure record: three projects that passed their tests and still didn't work, with all 138 review records and 25 escalations committed. The most useful thing I've built, in the sense that it taught me the most.
- **[llm-equities-paper-trading](https://github.com/muhriz-requiem/llm-equities-paper-trading)** and **[golden-trinity](https://github.com/muhriz-requiem/golden-trinity)** — trading pipelines published as negative results: one where the edge died at transaction costs, one where the headline performance turned out not to be in the database. Both kept because a negative result is still a result.
- **[gld-trading-platform](https://github.com/muhriz-requiem/gld-trading-platform)** — a paper-only trading system whose architecture validator (AST-based, deterministic) is stricter than its performance claims — and whose README says exactly where the validation stops.
- **[alice-shimada-bot](https://github.com/muhriz-requiem/alice-shimada-bot)** — Based on Alice Shimada from the anime, Girls und Panzer! This project is a Discord bot that can talk in calls, replies to text, and accompanies me while I'm working. Lots of fun commands too! (Sanitised public copy — the weights stay private.)

Mostly built on a GTX 1650 Ti, OpenCode, and whatever ideas I get. Reach me at muhrizmohammadharith@gmail.com.
